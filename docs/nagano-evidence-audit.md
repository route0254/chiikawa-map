# ナガセン関連 信憑性監査

最終更新: 2026-08-27

## 監査方針

公開中の68件を10～15件ずつ再調査します。噂を断定せず、ナガノ先生との関係性と場所特定の根拠を分けて確認します。

## 根拠の優先順位

1. ナガノ先生本人の公式SNS・ブログ・作品内の明示
2. 出版社・公式企画・自治体・店舗の公式発表
3. 写真、商品、外観、位置、旅程など複数要素の一致
4. ファン投稿・口コミのみの情報

1または2から場所まで直接確認できる場合は`confirmed`候補です。3による特定は`inferred`候補です。4だけの場合は掲載保留または削除候補とします。

## 内部監査の3区分

| 監査結果 | 公開上の扱い |
|---|---|
| 一次情報で場所まで直接確認 | `confirmed` |
| 複数の一致点があるが断定できない | `inferred` |
| 噂のみ、候補が複数、根拠を追跡できない | 掲載保留・削除候補 |

### 「推定・高確度」の扱い

公開上の区分は互換性を維持するため`confirmed`と`inferred`の2種類を継続します。そのうえで、次の条件をすべて満たす`inferred`は、`evidenceNote`の冒頭に「【推定・高確度】」と記載します。

- 本人発信や作品から、地域・店名の一部・商品などを直接確認できる
- 商品、外観、店内、ディスプレイ、旅程など複数の固有要素が一致する
- 同じ条件を満たす有力な別候補が見つからない

たとえば、本人投稿で「タカセ」までは確認でき、食品サンプルの順番、パフェ、店内設備が池袋本店2Fと一致する場合です。特定度が非常に高くても、本人発信で支店・階まで明示されていなければ公開上は「推定」を維持します。

## 1件ごとの確認項目

- ID・名称
- 現在の`evidenceStatus`
- 本人発信または公式発表の有無
- 店舗・地点まで特定できる根拠
- 別候補の有無
- 根拠URLが現在も閲覧可能か
- 現在の営業・閉店・移転状況
- 推奨判定
- `evidenceNote`修正案
- 掲載継続、修正、保留、削除候補のいずれか

## 反映ルール

- 調査・反映の承認を得た監査回のみ公開JSONを変更する
- 判定変更、掲載保留、削除候補は、根拠と変更案をサイト管理者へ報告する
- 承認後に`evidenceStatus`、`evidenceNote`、`evidenceUrl`、`evidenceCheckedAt`を更新する
- IDは変更しない
- 営業状況の確度とナガセン関連の確度を混同しない
