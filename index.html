    OFFICIAL GUIDE

    公式関連の使い方

    ちいかわ公式関連について

    ちいかわらんどなどの公式ショップ、常設施設、 公式コラボ、POP UP、イベント・展示などをまとめています。

    期間限定スポットは、終了日を過ぎると 自動的に地図から非表示になります。

    検索・都道府県から探す

    MAP上部の検索欄では、スポット名・住所・説明・シリーズ名などから検索できます。 「都道府県」と組み合わせれば、旅行先や近くのエリアだけに絞ることもできます。

    「◎ 現在地」で現在地付近へ移動でき、「地図 / 一覧」で表示方法を切り替えられます。 一覧では「◎ 近い順」「⌛ 終了が近い順」「あ 名前順」「▣ 地図範囲内」を利用でき、検索・絞り込み条件と組み合わせられます。 期間限定スポットは残り日数・開催までの日数も表示し、「⚠ まもなく終了（7日以内）」だけに絞れます。 「♡ 行きたい」と「✓ 行った！」はこのブラウザ内に保存され、それぞれ保存済みだけの表示にも対応しています。 「🔗 このスポットを共有」は1スポットを直接共有、「🔗 条件を共有」は現在の検索・絞り込み状態を共有できます。 位置情報・行きたい・行った情報をサーバーへ送信する機能はありません。

    絞り込みの例

    ちいかわらんどだけ探したい 「シリーズ・施設」→「ちいかわらんど」
    期間限定POP UPを探したい 「公式関連の種類」→「POP UP」＋「開催期間」→「期間限定」
    公式の飲食スポットだけ探したい 「関連」→「ちいかわ公式」＋「スポットの種類」→「グルメ」

    各フィルターの意味

    シリーズ・施設
    ちいかわらんど、ちいかわパーク、ラーメン 豚など、特定シリーズだけを探せます。
    公式関連の種類
    公式ショップ、公式施設、コラボ、POP UP、イベント・展示に分類しています。
    開催期間
    常設か期間限定かを分類しています。終了済みの期間限定スポットは通常表示されません。

    予約表示の考え方

    予約不可事前予約制度なし。通常入場や整理券方式の場合があります。
    予約可事前予約できますが、原則として予約なしでも利用できます。
    予約優先予約者が優先。空きがあれば予約なしでも利用できる場合があります。
    要予約原則として事前予約・チケットなどが必要です。
    要確認日付や混雑状況などで運用が変わるため、最新案内の確認をおすすめします。

    ※「予約」と「入場制限」は別に管理しています。 「予約不可」の店舗でも、混雑時に整理券などが必要になる場合があります。

    掲載情報について

    営業時間・開催期間・予約・入場方法などは、 原則として公式サイト・施設公式情報を基準に整理しています。 訪問前には各スポットの最新情報もご確認ください。

    NAGANO GUIDE

    ナガセン関連の使い方

    ナガセン関連とは？

    ナガノ先生本人が実際に訪れた場所、SNSや作品などで紹介したお店、 そのほかナガノ先生と明確なゆかりがある場所をまとめるカテゴリです。

    「ナガノマーケット」は公式ショップのため、こちらではなく 「ちいかわ公式」側に分類しています。

    検索・都道府県から探す

    MAP上部の検索欄から店名・地名を検索できます。 都道府県や「紹介 / 訪問 / ゆかり・関連」「確定 / 推定」の絞り込みと併用できます。

    「◎ 現在地」で現在地付近へ移動でき、「地図 / 一覧」で巡礼候補を見比べられます。 一覧では「◎ 近い順」「⌛ 終了が近い順」「あ 名前順」「▣ 地図範囲内」を既存の絞り込みと併用できます。 気になる場所は「♡ 行きたい」、訪問済みは「✓ 行った！」として保存でき、それぞれ保存済みだけの表示にも対応しています。 「🔗 このスポットを共有」から1スポットを直接共有でき、「🔗 条件を共有」では現在の検索・絞り込み状態を共有できます。 行きたい・行った等の保存内容はこのブラウザ内だけに保持され、条件共有URLにも含まれません。

    3つの分類

    紹介 本人のX・Instagram・作品などで、店や場所を明確に紹介したもの。
    訪問 本人が実際に訪れたことを、本人投稿・作品・公式媒体などから確認できるもの。
    ゆかり・関連 キャラクターデザインなど、本人との明確な関係が確認できる場所。

    「確定」と「推定」について

    ✓ 確定 本人のX・Instagram、作品内の明示、出版社・店舗・自治体などの公式情報から、その店・場所との関係を直接確認できたもの。
    △ 推定 作品の描写、食べた商品、外観、旅程、周辺スポットなどを照合すると特定度が高いものの、一次情報だけでは店名・地点まで完全には断定できないもの。

    「推定」は事実として断定する表示ではなく、ナガセン巡礼の有力候補です。 新しい一次情報が見つかった場合は「確定」へ変更し、誤りが判明した場合は修正・削除します。

    なお、この「確定 / 推定」は ナガノ先生との関係性や場所特定の確度 を示すものです。 現在の営業状況・営業時間・商品提供状況まで保証する表示ではありません。

    MOGUMOGUなどの作品について

    『MOGUMOGU食べ歩きくま』は、ナガノ先生自身の旅行・食体験が反映された イラストエッセイとして扱い、作品内で地域や場所が明示されるものは「確定」、 店舗を描写・メニュー・旅程などから照合したものは「推定」として分けて掲載します。

    ただし、根拠が「ナガノ先生おすすめらしい」といった噂だけのものや、 候補店が複数あって絞れないものは掲載しません。

    情報の確認方針

    本人のX・Instagram、出版社やイベント等の公式媒体、 店舗側の公式な言及など、一次情報または信頼性の高い情報を優先します。

    「ナガノ先生おすすめらしい」といった出典不明の情報だけでは掲載しません。 また、閉店・移転・商品終了なども可能な範囲で確認します。

    絞り込みの例

    ナガノ先生が訪れた飲食店を探したい 「関連」→「ナガノ先生」＋「スポットの種類」→「グルメ」＋「ナガノ先生関連の種類」→「訪問」
    紹介された場所をまとめて見たい 「関連」→「ナガノ先生」＋「ナガノ先生関連の種類」→「紹介」

    ナガセン関連には「確定」と「推定」の両方を掲載しています。 ピンを選ぶと詳細上部に ✓確定 / △推定 が表示され、根拠リンクも確認できます。 推定スポットは断定情報ではない点をご理解のうえ、巡礼候補としてお楽しみください。
